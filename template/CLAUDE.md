# 시험 대비 학습 볼트: 공통 규칙

이 폴더는 Obsidian 볼트의 루트이고, 한 과목의 강의자료 전체다. 사용자는 Obsidian으로 강의 PDF를 보면서 오른쪽 Claudian 창에서 질문한다. Claudian은 이 폴더에서 Claude Code를 실행하므로 경로는 모두 이 폴더 기준이다(예: `강의자료/03강.pdf`).

상세 학습 규칙은 맨 아래에서 불러오는 `AGENTS.md`에 있다.

## 폴더

- `강의자료/`: 강의 슬라이드·과제·퀴즈 PDF. 사용자가 넣는다.
- `지식베이스/지식베이스.md`: AI가 강의자료 전체를 블록 단위로 정리한 파일.
- `시험쪽집게/시험쪽집게.md`: 출제 예상 문제 누적 파일.
- `html필기노트/`: AI가 만든 HTML 필기, 해설, T/F 퀴즈, 모의고사.
- `_pdf_원본백업/`: PDF를 처음 고칠 때 원본이 자동으로 복사되는 곳. 지우거나 고치지 않는다.
- `.tools/`: PDF 필기·해설 삽입 도구(Python, PyMuPDF).

## 설명 기준

- 한국어로 답하고, 영어 용어는 처음 나올 때 풀어 쓴다. 답은 슬라이드 내용을 근거로 한다. 슬라이드에 없는 내용은 "슬라이드 밖 설명"이라고 구분한다.

## 질문을 받으면

1. 어느 슬라이드인지 정한다. 사용자가 파일과 쪽 번호를 말하면 그대로 쓴다. 말하지 않았으면 `python -I .tools/annotate_pdf.py current`로 열려 있는 PDF와 쪽을 본다. 이 값은 Obsidian이 마지막으로 저장한 값이라 틀릴 수 있으므로 답 맨 앞에 "(파일명 p.N 기준)"이라고 밝힌다.
2. 해당 쪽을 읽는다: `python -I .tools/annotate_pdf.py read "<파일>" <쪽>`. 텍스트가 없으면(그림 슬라이드) Read 도구로 PDF의 그 쪽을 이미지로 본다.
3. 채팅으로 답한다. 이때는 PDF를 건드리지 않는다.

## PDF에 필기 남기기

- 사용자가 "필기해줘", "메모해줘", "PDF에 남겨줘"처럼 요청했을 때만 PDF에 쓴다.
- 명령: `python -I .tools/annotate_pdf.py add "<파일>" <쪽> --note "Q: <질문>\nA: <답 요약>" [--quote "<쪽 안의 원문 그대로>"] [--color yellow|green|blue|pink|orange]`
- 슬라이드 위에 바로 보이는 빨간 글자(예: "★ 시험 출제")는 `label`, 슬라이드에 표를 그려 넣을 때는 `table` 명령을 쓴다(`--help` 참고).
- `--quote`에는 그 쪽 텍스트에 실제로 있는 문구를 그대로 넣는다. 찾으면 하이라이트, 못 찾으면 스티커 메모가 붙는다. 결과의 `type`과 `quote_found`를 사용자에게 알린다.
- 잘못 쓴 필기는 `list`로 확인하고 `remove --xref <번호>`로 지운다. Claude가 만든 필기만 지워진다.
- 필기 직후 알린다: "Obsidian에서 해당 PDF 탭을 닫고 다시 열면 보입니다."

## 지켜야 할 것

- 원본 보호: PDF는 반드시 `.tools/` 도구로만 고친다. 도구가 처음 쓸 때 원본을 `_pdf_원본백업/`에 복사한다. 백업 폴더는 지우거나 덮어쓰지 않는다.
- 사용자가 만든 보고서·필기의 HTML 원본을 고칠 때는 이전본을 같은 폴더에 `_이전본`을 붙여 남긴 뒤 고친다.
- 강의자료는 수업을 듣는 본인 공부용이다. 강의 슬라이드 원본을 볼트 밖으로 올리거나 공개하는 작업은 하지 않는다.
